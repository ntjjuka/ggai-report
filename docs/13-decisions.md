## A. 결정됨
| # | 결정 | 대안 | 이유 |
|---|---|---|---|
| ADR-01 | **재검토 중(15 문서)**: Spring Boot 3.5.x / Java 21 vs Node.js(TypeScript, Next.js). PostgreSQL 16은 공통. 사용자 결정 대기 | Python | 15 문서 비교표·추천 참조 |
| ADR-02 | 큐는 DB(`FOR UPDATE SKIP LOCKED`) + 하트비트 | Redis/RabbitMQ/Kafka | 인프라 1개 축소, 재기동 복구·멱등 체크포인트가 DB에 자연스럽게 결합 |
| ADR-03 | 프론트 서버 렌더(Thymeleaf+HTMX+Tailwind) | Next.js 분리 | 1인 백엔드 구현 속도, 공유 페이지 신뢰성. REST는 유지해 SPA 전환 여지 |
| ADR-04 | LLM: Claude. 종합 `claude-opus-5-5`, 청크 `claude-sonnet-5-5`, 폴백 `claude-opus-4-8` | Gemini(toksai/Tokka), GPT | 구조화 출력·프롬프트 캐시·1M 컨텍스트·Java SDK. 모델명은 설정값 |
| ADR-05 | 근거는 **메시지 ID**로만 인용, 서버가 텍스트를 붙인다 | LLM이 인용문 출력 후 문자열 대조(toksai) | 환각 0, 토큰 절약, 화자 검증 가능 |
| ADR-06 | 통계는 결정적 계산 → LLM에 "숫자 사실"로 제공, 숫자 생성 금지 | LLM이 숫자 추정 | 숫자 환각 차단, 재현성 |

| ADR-08 | MVP 인증 없음: 소유자 토큰 쿠키 + 공유 토큰(해시 저장) | 이메일 매직링크 | 범위 축소. 토큰 분실=접근 불가를 UI에 고지 |
| ADR-09 | 원문 암호화 보관 7일, 보고서는 사용자 삭제까지 | 즉시 삭제 | 재생성(다른 초점·질문) UX. 만료 후 재생성 불가 표기 |
| ADR-10 | 페르소나 「까비서」, 톤 반말 고정(사용자 결정 2026-11-03). 이름은 설정값으로 유지 | 다른 이름, 존댓말 | 캐릭터 모순(비서+반말)이 화법의 축. 코드엔 이름 하드코딩 금지 |

| ADR-14 | 샘플링 시 연속 문맥 창 방식(toksai) + 커버리지 공개 | 균등 개별 샘플 | 질문-답 문맥 보존 |
