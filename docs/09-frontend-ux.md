# 09. 프론트엔드 · UX

> 2026-11-03 Node 구현 기준으로 갱신 (docs/18 P0-9). 화면·카피·단계는 `src/app/**/page.tsx`, `src/components/**`에서 그대로 옮겼다. 위저드 단계 수는 `src/components/setup/Wizard.tsx`의 `step ===` 분기를 세어 **7단계**로 확정했다.

## 1. 원칙
- 모바일 우선(카톡은 폰에서 내보낸다), **한 화면에 한 질문**(설정은 `/setup` 위저드, 통계는 카드 스토리), 보고서는 스크린샷을 찍고 싶게, 공유 페이지는 원문을 흘리지 않게(인용된 문장만).
- 구현: Next.js App Router **서버 컴포넌트**가 기본(보고서·대시보드·공유·안내 페이지), 상호작용이 필요한 조각만 클라이언트 컴포넌트(`Wizard`, `StoryViewer`, `ReportStatus`의 대기/실패/공유/삭제/새 보고서 폼). Tailwind v4 + `globals.css`의 토큰(`--color-ink/muted/line/paper`, 파스텔 6색 `lavender/pink/peach/mint/yellow/beige`, `accent #3b82f6`)과 공용 클래스(`.card`, `.card-pastel`, `.option-card`, `.bubble`, `.glow-card`, `.progress-gradient`, `.btn-primary/.btn-secondary`). 폰트 Pretendard 자체 호스팅, 외부 CDN 0.
- **다크 모드 미구현**(`prefers-color-scheme` 분기 없음). 포커스 링도 브라우저 기본.
- **UI 보이스**(17 결정 5, 14 §2.1): UI 카피는 **존댓말**("~요")이고 페르소나는 **3인칭**으로 등장한다("까비서한테 어떤 대화를 보여 줄까요?", "까비서가 읽는 중…", "까비서한테 새 보고서 부탁하기"). 보고서 **본문**은 페르소나 1인칭 **반말 기본**(톤 옵션 `POLITE`로 존댓말). 예외: 랜딩(`/`) 히어로·신뢰 3칸은 페르소나가 직접 말하는 반말(보고서 보이스의 미리보기)로 쓰여 있다 — 14 §2.1에 예외로 명시.
- 페르소나 이름은 모든 화면이 `PERSONA_NAME`(기본 까비서)에서 읽는다(하드코딩 없음).

## 4. 공유 카드 스펙 (`src/app/r/[token]/card.png/route.tsx`, `ReportView` 15번)
- PNG: `next/og` `ImageResponse` 1080×1920, 배경 `linear-gradient(135deg, #ff4d6d 0%, #ff8a3d 45%, #ffd23f 100%)`, 흰 글자, 패딩 140/96px, 폰트 `public/fonts/Pretendard-Bold.otf`(weight 700).
- 구성: 상단 "{페르소나}의 판정"(40px) · 중앙 헤드라인(길이 ≤14자 104px / ≤24자 88px / 그 외 72px, `word-break: keep-all`, 그림자) + 서브라인(44px) · 하단 서명 멘트(좌) · 페르소나 이름(우) 34px.
- 이모지·변형 선택자(`\p{Extended_Pictographic}`, U+FE0F, U+200D)는 satori가 외부 CDN에서 글리프를 받으려 하므로 **제거**한다(오프라인·컨테이너 안전). 페이지 안 카드(15번)에는 `shareCard.emoji`가 보인다.
- 텍스트 길이: 헤드라인 ≤40자(검증기, 초과 시 `verdict.headline`로 대체), 서브라인 ≤30자(초과 시 29자+`…`).
- 헤더: `Cache-Control: private, max-age=300`, `X-Robots-Tag: noindex`. 공유 비활성·없는 토큰 → 404 텍스트.
- OG(`/r/{token}` `generateMetadata`): `title` = 판정 헤드라인, `description` = "{페르소나}의 판정 · {서브라인}", `openGraph.images` = `/r/{token}/card.png`(1080×1920), `robots: noindex, nofollow`.
- 페이지 안 카드는 `.glow-card` 그라디언트 CSS로 같은 구성(이모지 포함). "이미지로 저장" 버튼은 없다 — PNG는 OG 이미지 또는 URL 직접 접근으로 얻는다.

페르소나 아바타(🧑‍💼 원형 + 🤔 말풍선, 방사형 파스텔 배경) · 제목 "{페르소나}가 읽는 중…" · 그라디언트 진행 바(`progress.pct`, 최소 6%) · 본문 = `progress.message`(없으면 "{ETA}분 안에 보고서가 나올 거예요.") · 각주 "{ETA}분 안에 보고서가 나올 거예요. 이 페이지를 닫아도 링크로 돌아오면 이어서 볼 수 있어요." 3초 폴링, 상태가 바뀌면 `router.refresh()`.
**ETA**(`/c/[id]/reports/[seq]/page.tsx`) = `clamp(2, 10, ceil(messageCount / 6000) × 2)` 분. **생성 시간 카피 통일**: "보통 2~5분, 긴 대화는 최대 10분"(위저드 7단계 문구 "통계 보고서는 바로 나오고, {페르소나}의 보고서는 보통 2~5분, 긴 대화는 최대 10분 걸려요."). 02 §2·§4와 같다.
### 5.3 실패 화면 `FailedScreen`
😮‍💨 · "{페르소나}가 보고서를 끝내지 못했어요" · `error.message`(04 §4.7 코드별 문구) · "오류 코드 {code}" · `retryable`이면 "다시 시도" 버튼(진행 중 "다시 줄 서는 중…") → `POST /retry` → refresh. 재시도 불가 코드(`COST_LIMIT_EXCEEDED`·`LLM_REFUSED`·`LLM_BAD_REQUEST`·`RAW_EXPIRED`)는 버튼 없음.
### 5.4 취소 화면
"취소된 보고서예요" + "대화로 돌아가기".
### 5.5 대기 중 콘텐츠 = Tier 0
위저드 7단계에서 "보고서 만들기"를 누르면 confirm → create 후 `/c/{id}/story?then=/c/{id}/reports/{seq}?show=writing`으로 이동한다. 사용자는 **통계 스토리 7장을 넘기며 기다리고**, 마지막 장의 "{페르소나} 보고서 보기 →"로 대기 화면(또는 완성 화면)에 도착한다. 복귀는 링크 + 쿠키(이메일 알림은 미구현, 10 §3).

## 7. 접근성·성능 (코드 확인)
- 보고서·공유·대시보드·안내 페이지는 서버 렌더라 JS 없이도 읽힌다. 클라이언트 JS는 위저드·스토리 넘김·폴링·공유/삭제 버튼에만.
- 도넛 차트 `aria-label`, 히트맵·막대의 `title` 툴팁(요일·시각·개수), 뒤로가기 버튼 `aria-label="뒤로"`. 색 대비 AA 검증·Lighthouse 측정은 미실시.
- 외부 요청 0(폰트·CSS·차트 모두 자체). Tailwind v4 산출 크기 측정은 미실시.
