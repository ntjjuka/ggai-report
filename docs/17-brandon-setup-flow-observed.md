# 17. 실측: What Brandon Thinks 한국어 설정 흐름 (사용자 제공 스크린샷, 2026-11-03)

> 출처: 사용자가 직접 캡처한 `https://www.whatbrandonthinks.com/ko/setup?from=report&back=%2Fc%2F{uuid}%2Freports%2F1` 화면 10장. **공식 사이트의 첫 직접 증거**다(이전 조사는 검색 요약 기반). 설계 문서(02/06/09)와의 차이는 18 문서(갭 분석)에서 다룬다.
> URL 의미: `/ko/setup` 은 7단계 위저드. `from=report&back=/c/{id}/reports/1` 은 기존 리포트 화면에서 "새 대화/새 리포트" 진입 시 되돌아갈 경로. 즉 설정 위저드는 리포트 페이지에서 재진입 가능하다.

## 0. 공통 UI 패턴
- 상단: 뒤로가기 화살표 + 진행 바 + `n/7` 카운터. 한 화면에 질문 하나. 선택지는 큰 카드(아이콘 + 제목 + 회색 부제).
- **UI 카피는 존댓말(~요)**, 페르소나는 3인칭으로 등장한다("브랜든한테", "브랜든이 누가 누군지 알아요"). 보고서 본문 톤과 UI 톤은 분리되어 있다.
- 주 버튼: 검정 둥근 버튼 "계속 →" (조건 미충족 시 회색 비활성).

## 1단계 — 대화 유형 "브랜든한테 어떤 대화를 보여 줄까요?"
| 카드 | 부제 |
|---|---|
| 연애 💌 | 애인, 썸, 전 애인… |
| 친구 단톡방 😂 | 과동기, 여행 단톡방, 운동 모임… |
| 친구 한 명 🫶 | 베프, 소꿉친구, 회사 절친… |
| 가족 🏠 | 가족 단톡방, 엄마나 아빠, 형제자매… |
| 회사 / 팀 📋 | 팀 단톡방, 동료, 상사… |
| 기타 🤷 | 룸메이트, 이웃, 그 밖의 모든 대화… |
→ 우리 설계의 `focus`(AUTO/ROMANCE/FRIENDS/GROUP/WORK)보다 **먼저** 묻고, 친구를 "단톡방/한 명"으로 나누며 "가족"과 "기타"가 있다. AUTO 선택지는 없다.

## 2단계 — 앱 선택 "어떤 앱에서 나눈 대화예요?"
카카오톡 / WhatsApp / iMessage / Instagram / Messenger / LINE (브랜드 아이콘). 카카오톡이 1순위로 표시(ko 로케일).

## 3단계 — 업로드 "카카오톡 대화 올리기"
- 큰 드롭존: TXT 아이콘, "눌러서 올리기 / 또는 끌어다 놓기". 하단 "🛡 올린 데이터는 비공개로 지켜져요 [자세히 보기]".
- 안내 문구(원문):
  - "Windows용 카카오톡: 채팅방을 열고 `Ctrl` + `S` 를 눌러 파일을 저장하세요."
  - "Mac용 카카오톡: 채팅방을 열고 오른쪽 위 ≡ 버튼을 누른 다음, 채팅방 설정에서 대화 내용을 저장하세요."
  - "컴퓨터에는 최근 메시지만 있을 수 있어요. 대화 전체를 보내려면 📱 [휴대폰에서 보내 주세요]" (링크 → 휴대폰/이메일 경로)
- 업로드 직후 드롭존이 **그라디언트 카드**로 바뀜: 큰 숫자 "108,231" + "메시지" + 배지 "📶 신호 최상" + 하단 "눌러서 대화 바꾸기". 파싱이 **즉시(클라이언트 또는 빠른 서버)** 끝나고 메시지 수와 **신호 품질 등급**을 보여준다. "계속" 활성화.

## 4단계 — 참여자 확인 (제목 없음)
- 상단 편집 가능한 대화방 이름 필드("한우방" ✎).
- 참여자 목록: 색 점 + 이름 + `34,996 💬 32%` + 비율 막대. 메시지 수 내림차순. 봇 계정(채팅봇 326, 플레이봇 81)도 그대로 목록에 있음(자동 제외 없음, 0% 표시).
- 하단 카드: **"한 사람은 한 번만 나오게 해 주세요"** — "한 사람이 다른 이름이나 번호로 여러 번 나오면, 브랜든이 서로 다른 사람으로 착각해서 리포트를 잘못 쓸 수 있어요." 버튼 **"프로필 합치기"**.
- 이 화면에는 **"당신은 누구인가요?" 선택이 없다**(이후 단계에도 보이지 않음). → 업로더 식별이 필수가 아닐 가능성(또는 다른 유형에서만 묻거나, 리포트 안에서 선택). 추가 스크린샷으로 확인 필요.

## 5단계 — "이름 정리하기"
"별명이랑 이모지는 간단한 이름으로 바꿔 주세요. 그래야 브랜든이 누가 누군지 알아요." 각 참여자: 색 아바타(첫 글자) + 편집 가능한 이름 입력. 봇 이름도 편집 대상.
→ 표시 이름 정리를 **별도 단계**로 분리. LLM이 이름을 잘 다루게 하려는 목적을 사용자에게 설명.

## 6단계 — "리포트 언어를 골라 주세요"
"대화 언어와 달라도 괜찮아요." KR 한국어 · GB 영어 · ES 스페인어 · FR 프랑스어 · IT 이탈리아어 · DE 독일어 · BR 포르투갈어(브라질) · PT 포르투갈어(포르투갈) · NL 네덜란드어 · ID 인도네시아어 · IL 히브리어 · SA 아랍어 · TR 튀르키예어 · 🌍 다른 언어.

## 7단계 — 이메일 "리포트를 어느 이메일로 보내 드릴까요?"
- 이메일 입력 → "인증 코드 받기 →" → "이메일을 확인해 주세요 / {email}에 보낸 6자리 코드를 입력해 주세요." 6칸 코드 입력, "다른 이메일 쓰기".
- 인증 후: "리포트를 이 주소로 보내 드려요" + 체크 표시된 이메일 + "이메일이 틀렸나요? 다른 이메일 사용하기" + 버튼 **"리포트 만들기"**(로딩 스피너, 무지개 글로우).
→ 이메일 인증 코드가 **계정·전달·복귀 수단**. 결제·미리보기는 리포트 생성 이후 화면(미확인).

## 설계 반영 결정 (즉시 적용)
1. **위저드 순서 채택**: 유형 → (앱: 카카오톡 고정, UI만 표시) → 업로드(즉시 파싱 + 메시지 수 + 신호 등급) → 참여자 확인(비율 막대 + 프로필 합치기) → 이름 정리 → (언어: 한국어 고정, 필드만 보존) → 생성. 이메일 단계는 MVP에서 **선택**(소유자 쿠키 유지), v2에 인증 코드 도입.
2. **유형 6종**으로 `focus` 확장: `ROMANCE | FRIENDS_GROUP | FRIEND_ONE | FAMILY | WORK | OTHER`(기존 FRIENDS/GROUP/AUTO는 매핑). 점수 세트·프롬프트 지침을 유형별로.
3. **업로더 선택은 선택 사항**으로 완화(연애·친구 한 명 유형에서는 권장 표시). 미선택 시 "(나)" 표식 없이 전원 평가, "내가 너라면"은 업로더가 있을 때만 2인칭.
4. **신호 등급** 계산: 메시지 수·참여자·기간 기준 `최상/좋음/보통/약함`(예: 텍스트 ≥ 3,000 & 활성일 ≥ 30 → 최상). 업로드 응답과 카드에 표시.
5. **UI 카피 존댓말, 보고서 본문 반말** 분리. 페르소나 3인칭 호칭("까비서한테 어떤 대화를 보여 줄까요?").
6. 업로드 안내 문구(Windows Ctrl+S, Mac ≡ 메뉴, "컴퓨터에는 최근 메시지만")를 가이드에 그대로 반영.
7. 대화방 이름 편집, 봇 자동 제외(기본 체크, 사용자 해제 가능) — Brandon은 자동 제외하지 않지만 우리는 기본 제외가 낫다(통계 왜곡 방지).
8. `report_language` 필드(기본 ko) 보존. 다국어는 v2.

## 실측 2: 통계 스토리 7단계 (추가 스크린샷, 2/7~6/7 확인)
설정 위저드와 별개로 **무료 통계를 카드 스토리 7장**으로 보여준다(진행 바 + "다음 →"). 1/7(개요 추정)과 7/7(리포트 CTA 추정)은 미확인. 파스텔 카드(연보라·분홍·살구·민트·노랑·베이지), 큰 숫자 + 작은 단위, 제목은 구어체 명사구.

| 단계 | 제목 | 카드 내용(원문 라벨) |
|---|---|---|
| 2/7 | **누가 더 많이, 누가 먼저** | ① "대화 지분" 도넛 + #1~#5 이름·비율, "나머지 19%" ② "먼저 말 건 사람" 가로 막대(상위 5명, 비율) ③ "서로를 부르는 말" — 한 사람이 가장 자주 쓴 호칭("아기털뭉치 → 언니 15번") |
| 3/7 | **대화의 리듬** | ① "칼답률" 시상대(1·2·3위 메달, 74%/71%/69%) 설명 "1분 안에 보낸 답장 비율" ② "메시지가 가장 많았던 날" 1,672개 · 2025년 3월 17일 ③ "최장 연속 대화" 94일 ④ "가장 길었던 침묵" 20일 ⑤ "시간대별" 24시간 막대(라벨 밤 12시·오전 6시·낮 12시·저녁 6시) + 캡션 "밤 10시~새벽 5시 11% · 가장 활발한 시간 오후 5시" |
| 4/7 | **가장 긴 메시지** | 사람별 카드: 이름, "411자", 날짜, 말풍선 미리보기(접힘) + "더 보기". 상위 2명 |
| 5/7 | **모든 건 여기서 시작** | 첫날 날짜 + 그날 메시지 말풍선 4~5개(이름 라벨, 연속 메시지는 이름 생략) |
| 6/7 | **그리고 지금, 여기까지** | 마지막 날 날짜 + 그날 메시지 말풍선 |

→ 우리 Tier 0(15 §B.4)와 정확히 같은 자리. **카드 구성을 이대로 채택**하고 통계에 다음 지표를 추가한다: 칼답률(답장 중 ≤60초 비율), 최장 연속 대화일수, 밤 10시~새벽 5시 비율, 가장 활발한 시간, 호칭(서로를 부르는 말), 첫날/마지막날 메시지, 사람별 최장 메시지. 캡션 톤은 **수치 중심 존댓말 없는 명사구**(Brandon의 통계 카드에는 페르소나 농담이 없다). 까비서 한 줄은 카드 아래 별도 영역으로 둔다.

### 7/7 **자주 쓰는 말** (추가 스크린샷)
| 카드 | 내용 |
|---|---|
| 웃음 지문 | ㅋ 개수 순위 #1~#4("ㅋ×24,614"), 하단 "최고 기록 ㅋ 85연타 · 이진호"(한 메시지 최장 ㅋ 연속) |
| 말버릇 | "존맛 ×6", "넴 ×2" + 설명 "평균적인 한국 채팅보다 몇 배 더 쓰는지." → 일반 채팅 대비 **상대 빈도**(기준 코퍼스 대비 비율)로 뽑은 특이 어휘 |
| 가장 많이 쓴 단어 | #1~#5 (진솔·어우·언니·까부장·까부) — 불용어 제거 후 빈도 순. 호칭·별명이 올라옴 |
| 가장 많이 쓴 이모지 | 이모지 5개 가로 나열 |
| 이모티콘 | 총 "1,405개" + 사람별 비율 막대(상위 5명) |
버튼: **"리포트 보기 →"**

### 생성 대기 화면
페르소나 아바타(모자·선글라스·콧수염 일러스트) + 주변 색점 + 🤔 말풍선, 문구 **"브랜든이 생각하는 중…"**, 그라디언트 진행 바, 하단 **"2분 안에 리포트가 나올 거예요."** → 우리: "까비서가 읽는 중…" + "2분 안에 보고서가 나올 거예요." (예상 시간은 플랜에서 계산: 단일 패스 ~2분, 청크 모드 ~n분)

→ 통계 추가 지표: ㅋ 순위·최장 ㅋ 연타, 말버릇(기준 대비 상대 빈도), 최다 단어 5, 최다 이모지 5, 이모티콘 총계·사람별 비율. 통계 스토리 최종 구성: 1 개요(추정) · 2 누가 더 많이, 누가 먼저 · 3 대화의 리듬 · 4 가장 긴 메시지 · 5 모든 건 여기서 시작 · 6 그리고 지금, 여기까지 · 7 자주 쓰는 말 → 리포트 보기.
