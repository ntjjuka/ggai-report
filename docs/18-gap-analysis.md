### 2.2 우리가 빠뜨린 상태·카피
- 상태: `업로드됨(파싱 요약 카드)`, `대화 바꾸기`, `프로필 합치기 중`, `이메일 인증 대기/완료`, `생성 버튼 활성 조건` — 06의 상태 머신은 보고서만 다루고 **설정 진행 상태**(어느 단계까지 했는지)를 저장하지 않는다. 위저드 중간 이탈 후 복귀하면 처음부터다. → `conversation.setup_step`(또는 클라이언트 상태 + 서버 `participants_confirmed_at` 재사용) 명세 필요.
- 카피(채택 권고, 17 원문): "눌러서 올리기 / 또는 끌어다 놓기", "올린 데이터는 비공개로 지켜져요 [자세히 보기]", "컴퓨터에는 최근 메시지만 있을 수 있어요", "한 사람은 한 번만 나오게 해 주세요", "별명이랑 이모지는 간단한 이름으로 바꿔 주세요", "대화 언어와 달라도 괜찮아요", "이메일을 확인해 주세요 / 6자리 코드", "다른 이메일 쓰기", "리포트 만들기". 09 §5 진행 카피는 좋지만 **설정 단계 카피는 0줄**이다.
- 17 결정 비판: ①(이메일 선택) 거꾸로. ②(6종) 반영 안 됨. ③(업로더 선택) 영향 분석 없음 — 1:1·연애·친구 한 명은 "내가 너라면"의 2인칭과 `balance` 부호가 업로더에 의존하므로 **필수 유지**가 맞고, 단톡만 선택이 합리적. ④(신호 등급) 임계값은 좋으나 API 미노출. ⑤(UI 존댓말/본문 반말) 좋음 — 14 §2에 UI 톤 규칙으로 승격 필요. ⑦(봇 기본 제외) 방향은 맞지만 탐지 규칙이 없다(§9).

## §10. 그 밖의 차이·누락 (17 결정 비판 포함)

1. **페르소나 전략**: 원 서비스는 캐릭터 3명(Brandon/Clara/Diego)으로 "같은 대화, 다른 시선"을 재구매 동기로 쓴다. 14 §2는 까비서 1명을 깊게 설계했고 이는 옳지만, `persona_name` 컬럼이 있는데도 두 번째 캐릭터의 **자리**(언제 등장, 어떤 대조)가 어디에도 없다. P2 설계 메모라도 14에 두어야 한다.
2. **Personal read(나에 대한 보고서)**: 여러 대화를 합쳐 업로더를 읽는 라인. 우리 데이터 모델(1 대화 : N 보고서, 소유자=쿠키)로는 "내 대화들"을 묶을 주체가 없다 — 이메일 신원(P0)이 선행 조건. P2.
3. **"앱 선택" 단계 유지 결정(17-1)**: 선택지 1개 단계는 사용자에게 "왜 묻지?"만 남긴다. 삭제하거나 수요 측정(알림 신청)으로 바꿀 것.
4. **Tier 0 포지셔닝(15 §B.4)**: 원 서비스는 무료 통계를 팔지 않는다(무료는 "실제 보고서의 미리보기"). 통계 무료 입구는 클론(.co "Free Chat Statistics")의 전략이다. Tier 0는 대기 화면·즉시 공유 카드로 쓰고, 랜딩의 약속은 "다 읽고 솔직하게"에 집중.
5. **UI 톤(17-5)**: 좋은 결정이지만 14 §2 캐릭터 시트에 "UI에서는 3인칭·존댓말, 본문은 1인칭·반말" 규칙이 없고 09 §2 히어로 카피("…말해줌")는 반말이다. 14 §2에 "UI 보이스" 절 추가.
6. **"신호 등급" 임계값(17-4)**: 코드(`story.ts`)는 텍스트 ≥3,000 & 활성일 ≥30 → 최상. 원 서비스 기준은 미확인이고 108k 메시지가 "최상"이었다는 점만 안다. 등급 사유(기간 짧음·참여자 1명 과점·PC 내보내기 의심)를 함께 보여 주면 가이드로 되돌리는 장치가 된다.
7. **참여자 상한·단톡 UX**: 09 §6 "30명+ 검색 필터, 10개 미만 자동 제외 토글" — 원 서비스는 자동 제외 없이 비율 막대로 보여 주고 사용자가 판단. 자동 제외는 유지하되 "제외됨 N명 보기"로 투명하게.
8. **보고서 페이지의 "한 편의 글" 감각**: 원 서비스 샘플 제목("Three friends, one dinner, and the 'tomorrow people' problem")은 **글 제목**이다. 09 §3은 카드 14장. 14 §3의 조어 헤드라인이 카드 UI에서 살아남을지 — 판정 카드를 "글의 첫 장"처럼 큰 타이포로 두는 결정이 필요.
9. **면책·안전은 동급 이상**: 10 §6(1393 안내, 미성년 신호 톤 하향)은 원 서비스 공개 카피에 없는 강점. 유지.
10. **파서·접지·숫자 결정성(03/07/08)은 원 서비스가 공개한 어떤 것보다 구체적** — 차별점으로 랜딩에서 "근거 없는 농담은 안 해요"로 팔 것(현재 09 §2 히어로에는 없음).
